# Урок 10: Под капотом — Устройство Мап (Словарей)

Если слайс — это просто заголовок с указателем на массив, то мапа в Go — это сложный и невероятно оптимизированный механизм.

### Как это работает внутри (Хеш-таблицы и Бакеты)
Под капотом мапа (`hmap`) — это хеш-таблица. Данные в ней хранятся в "ведрах" (buckets).
1. Когда ты пишешь `m["apple"] = 5`, Go берет ключ `"apple"` и пропускает его через **хеш-функцию** (превращает строку в огромное нечитаемое число).
2. По этому числу Go определяет, в какой именно **бакет** нужно положить пару ключ-значение.
3. Один бакет вмещает ровно **8 пар** (ключ-значение).
4. Если бакет переполняется, Go выделяет новую память и начинает процесс **эвакуации** данных в новые бакеты.

Именно из-за того, что данные постоянно "перемешиваются" по бакетам при росте мапы, **итерация по мапе (через `for range`) не гарантирует порядок!** Каждый раз, выводя мапу в цикле, ты можешь получать ключи в разном порядке.

### Мапы — это Указатели
Когда ты создаешь мапу через `make(map[K]V)`, функция возвращает тебе **указатель** на структуру `hmap` в памяти (просто этот указатель скрыт от нас синтаксисом).
В отличие от слайсов, где заголовок копируется при передаче в функцию, передача мапы в функцию передает копию *этого скрытого указателя*. Обе копии смотрят на одну и ту же хеш-таблицу! 

Поэтому, если ты изменишь мапу внутри функции, она изменится и снаружи. Никакие `append` тут не ломают связи, как это бывает со слайсами.

## Задание

Давай докажем на практике, что мапы передаются по ссылке (указателю), и их можно безопасно изменять внутри других функций без возврата.

Создай файл `main.go` в директории `04_internals_deep_dive/02_map_internals`.

1. Создай функцию `modifyMap`, которая принимает один аргумент: мапу `m map[string]int`. Функция не должна ничего возвращать.
2. Внутри этой функции:
   - Добавь новый элемент в мапу (например, `"C++": 1983`).
   - Удали любой существующий элемент (используй функцию `delete(m, "Key")`).
3. В функции `main`:
   - Создай мапу с парой языков (например, "Go": 2009, "Java": 1995).
   - Выведи мапу в консоль до вызова функции.
   - Вызови `modifyMap`, передав туда свою мапу.
   - Снова выведи мапу в консоль.

Убедись, что оригинальная мапа изменилась. Пиши код и присылай `/[review]`!
