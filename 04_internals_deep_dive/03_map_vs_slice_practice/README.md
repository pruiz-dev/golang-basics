# Дополнительная практика: Мапы против Слайсов

Понимать разницу между этими двумя структурами данных — критически важный навык. Давай сведем всё, что мы о них знаем, в одну таблицу, а потом напишем программу, которая использует обе структуры.

### Сравнение: Слайс vs Мапа

| Характеристика | Слайс (`[]T`) | Мапа (`map[K]V`) |
| :--- | :--- | :--- |
| **Что это под капотом?** | Структура (pointer, len, cap) | Указатель на Хеш-таблицу (бакеты) |
| **Гарантия порядка?** | Да (индексы идут строго 0, 1, 2...) | **НЕТ!** Элементы раскиданы по бакетам. |
| **Как добавить элемент?** | `slice = append(slice, val)` | `m[key] = val` |
| **Что происходит при росте?**| Выделяется новый массив, данные копируются | Создаются новые бакеты, данные "эвакуируются" |
| **Сложность поиска** | Долгая (нужно перебрать весь слайс) | **Мгновенная (O(1))** по ключу |
| **Передача в функцию** | Копируется заголовок. `len` и `cap` могут рассинхронизироваться при `append`. | Копируется указатель. Все изменения сразу видны в оригинале. |

## Практическое задание: Подсчет слов

Один из самых классических примеров использования мап — это подсчет частоты элементов (сколько раз слово встречается в тексте).

Создай файл `main.go` в директории `04_internals_deep_dive/03_map_vs_slice_practice`.

1. Создай функцию `countWords`, которая принимает слайс строк (`words []string`) и возвращает мапу (`map[string]int`).
2. Внутри функции:
   - Инициализируй пустую мапу с помощью `make`.
   - Запусти цикл `for range` по слайсу `words`.
   - Для каждого слова увеличивай его счетчик в мапе на 1. *(Подсказка: если ключа в мапе еще нет, Go вернет `0`, так что можно смело писать `m[word] = m[word] + 1` или `m[word]++`)*.
   - Верни готовую мапу через `return`.
3. В функции `main`:
   - Создай слайс с повторяющимися словами: `[]string{"apple", "banana", "apple", "orange", "banana", "apple"}`.
   - Вызови `countWords`, передав туда слайс.
   - Выведи полученную мапу в консоль.

Это задание покажет тебе, как слайс (для хранения упорядоченного списка) и мапа (для мгновенного подсчета) работают вместе. Пиши код и присылай `/[review]`!
