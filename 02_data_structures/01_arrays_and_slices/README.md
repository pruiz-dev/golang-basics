# Урок 5: Структуры данных — Массивы и Слайсы (Срезы)

Мы закончили с базовой логикой (`01_basics`) и переходим к новой большой теме — структурам данных (`02_data_structures`). До этого мы хранили в переменных только одиночные значения. Теперь мы научимся хранить списки (коллекции).

В Go есть два способа хранить списки элементов одного типа: **массивы (arrays)** и **слайсы (slices)**.

### 1. Массивы (Arrays)
Главное правило массивов в Go — их **размер фиксирован**. Если ты создал массив на 5 элементов, в него нельзя добавить 6-й. Из-за этого строжайшего ограничения массивы в Go используются довольно редко.
```go
var arr [5]int // Массив из 5 целых чисел (изначально заполнен нулями)
arr[0] = 10    // Присваиваем значение первому элементу
```

### 2. Слайсы / Срезы (Slices)
Слайсы — это "массивы на стероидах". Они динамические: могут расти и уменьшаться. В 99% случаев в Go ты будешь использовать именно слайсы.
```go
// Создание слайса с начальными значениями (заметь, внутри [] нет числа)
fruits := []string{"Apple", "Banana"}

// Добавление новых элементов в конец слайса (очень важная функция append!)
fruits = append(fruits, "Orange")
```

### 3. Итерация по слайсу (цикл `for range`)
Чтобы пройтись по всем элементам слайса, в Go есть специальная (и очень удобная) форма цикла `for` с ключевым словом `range`.
Она возвращает сразу две переменные на каждом шаге: индекс (порядковый номер, начиная с 0) и само значение.
```go
for index, value := range fruits {
    fmt.Println(index, value)
}
```
*Совет: если тебе нужен только `value`, а `index` не нужен, используй пустой идентификатор `_`, чтобы компилятор не ругался: `for _, value := range fruits`.*
