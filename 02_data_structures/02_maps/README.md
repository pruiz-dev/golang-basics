# Урок 6: Словари (Maps)

В Go `map` (словарь, карта, хеш-таблица) — это встроенная структура данных для хранения пар "ключ-значение".
Она обеспечивает невероятно быстрый поиск, добавление и удаление элементов по ключу.

В отличие от слайсов, где индексом всегда выступает порядковый номер (0, 1, 2...), в мапах ключом может быть строка, число и даже некоторые другие типы (главное, чтобы их можно было сравнивать через `==`).

### 1. Создание и инициализация
Лучший способ создать пустую мапу — использовать встроенную функцию `make`.
Если ты просто объявишь мапу через `var m map[string]int`, она будет равна `nil`, и попытка записать в нее данные приведет к **падению программы (panic)**.
```go
// Создание пустой мапы (Ключ - строка, Значение - целое число)
ages := make(map[string]int)

// Или создание сразу с начальными данными:
colors := map[string]string{
    "red":   "#FF0000",
    "green": "#00FF00", // запятая в конце обязательна!
}
```

### 2. Чтение, запись и удаление
```go
ages["Alice"] = 25       // Добавление / Обновление
aliceAge := ages["Alice"] // Чтение (вернет 25)
delete(ages, "Alice")    // Удаление по ключу
```

### 3. Главная особенность: Проверка на существование
Что будет, если запросить ключ, которого нет в мапе? Go **не выдаст ошибку**. Он тихо вернет "нулевое значение" для типа (для `int` это `0`, для `string` это `""`).

Чтобы отличить реальный `0` от отсутствия ключа, используется синтаксис `comma ok` (запятая ок):
```go
age, ok := ages["Bob"]
if ok {
    fmt.Println("Bob найден, ему", age)
} else {
    fmt.Println("Bob не найден!")
}
```
