# Урок 2: Переменные, Константы и Базовые Типы Данных

Go — это статически типизированный язык. Это значит, что тип переменной (число, строка, логическое значение) проверяется на этапе компиляции.

В Go есть несколько способов объявить переменную:

1. **Классическое объявление (с ключевым словом `var`)**
Используется, когда нужно явно указать тип или когда переменная объявляется без начального значения.
```go
var age int = 25
var name string
```

2. **Краткое объявление (с оператором `:=`)**
Это самый частый способ внутри функций. Ты не указываешь тип явно — Go сам догадывается (выводит тип) на основе значения справа. Использовать можно *только внутри функций*.
```go
country := "Russia"
isDeveloper := true
```

3. **Константы (`const`)**
Если значение никогда не должно меняться во время выполнения программы, используем константы.
```go
const pi = 3.14
```

Базовые типы: `string`, `int`, `float64`, `bool`.

## Задание

Напиши программу, в которой:
1. Объяви константу с именем (например, `myName`), содержащую твое имя.
2. Объяви переменную с твоим возрастом (`age`), используя **строгое** объявление через `var` и указание типа `int`.
3. Объяви переменную-флаг (`isLearningGo`), которая равна `true`, используя **краткое** объявление (`:=`).
4. Выведи все три значения в консоль с помощью `fmt.Println`.
