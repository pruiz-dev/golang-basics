# Урок 4: Циклы (`for`)

В большинстве языков программирования есть сразу несколько видов циклов: `for`, `while`, `do-while` и `foreach`.
Создатели Go решили пойти по пути максимальной простоты и оставили **только один** цикл — `for`. Но благодаря своей гибкости он заменяет их все.

### 1. Классический цикл со счетчиком (как в C/Java/JS)
Состоит из трех частей, разделенных точкой с запятой: инициализация; условие; шаг.
```go
for i := 0; i < 5; i++ {
    fmt.Println(i) // Выведет числа от 0 до 4
}
```
*Обрати внимание: круглые скобки вокруг условия снова не нужны! А вот фигурные — обязательны.*

### 2. Цикл `for` как аналог `while`
Если тебе нужно выполнять код, пока истинно какое-то условие (и тебе не нужен счетчик `i`), ты можешь просто опустить первую и третью части.
```go
sum := 1
for sum < 100 {
    sum += sum
}
fmt.Println(sum)
```

### 3. Бесконечный цикл
Если убрать вообще все условия, цикл будет крутиться вечно. Выйти из него можно с помощью ключевого слова `break`. А чтобы пропустить текущую итерацию и перейти к следующей — используем `continue`.
```go
for {
    // Делаем что-то вечно
    if someCondition {
        break // немедленный выход из цикла
    }
}
```
