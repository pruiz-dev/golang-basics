# Урок 3: Управляющие конструкции — Условия (if / else)

В Go **не нужны круглые скобки** вокруг условия. Но фигурные скобки `{}` обязательны всегда, даже если внутри условия всего одна строчка кода.

Операторы сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`.
Для объединения условий используем логическое И `&&` и логическое ИЛИ `||`.

Важная фишка Go: Инициализация переменной внутри `if`. Эта переменная будет "жить" только внутри этого `if` (и связанных с ним `else`).
```go
if num := 10; num > 5 {
    fmt.Println(num, "больше пяти")
}
```

Также в Go хорошей практикой считается "Ранний возврат" (Early Return). Если возникает ошибка или аномальная ситуация — мы сразу возвращаемся через `return`, избегая лишних `else`. Использование переменной для формирования итогового сообщения вместо множественных вызовов `fmt.Println` также является Best Practice (принцип DRY).

## Задание

Напиши программу, которая делает следующее:
1. Объяви целочисленную переменную `score` (оценка) и присвой ей любое значение.
2. Объяви строковую переменную `message`.
3. Напиши блок логики:
   - Если оценка вне диапазона 0-100 — запиши в сообщение текст об аномальной ситуации, выведи в консоль и сделай `return`.
   - Если оценка от 70 до 99 (включительно) — запиши в сообщение `"Good job!"`.
   - Если оценка ровно 100 — запиши в сообщение `"Perfect!"`.
   - Если оценка 69 или меньше — запиши `"Needs improvement."`.
4. В конце сделай единственный вызов `fmt.Println`, который выведет `message`.
