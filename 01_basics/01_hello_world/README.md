# Урок 1: Структура программы на Go и твоя первая программа

Go — это компилируемый, статически типизированный язык, который делает упор на простоту и структурную ясность. Каждая исполняемая программа на Go следует предсказуемому шаблону.

Вот три ключевых компонента, которые нужны для базового приложения:

1. **Пакеты (`package`)**: Код на Go организован в пакеты. Каждый файл должен начинаться с объявления `package`. Чтобы создать исполняемую программу (ту, которую можно запустить напрямую, а не просто библиотеку), ты должен использовать специальное имя пакета: `package main`.
2. **Импорты (`import`)**: Само ядро Go минималистично, оно полагается на обширную стандартную библиотеку. Чтобы подтянуть эти библиотеки в свой файл, используется ключевое слово `import`. Для базового вывода текста в консоль используется пакет `fmt`.
3. **Точка входа (`func main`)**: Это всегда функция `main` внутри пакета `main`. Она не принимает никаких аргументов и не возвращает никаких значений.

## Задание

Напиши свою самую первую программу на Go.

1. Создай файл с именем `main.go`.
2. Напиши программу, которая выводит строку в консоль: `"Hello, World!"` (или `"Welcome to Go, Dima!"`).
3. Не забудь объявить правильный пакет, импортировать нужный пакет из стандартной библиотеки для вывода в консоль и определить функцию точки входа.
